O que é o protocolo HTTP ?

HTTP (do inglês Hypertext Transfer Protocol, ou Protocolo de Transferência de Hipertexto) é o protocolo de comunicação fundamental usado para transferir dados na internet entre um cliente (como o seu navegador) e um servidor web.

Como é usado na Web ?

O HTTP é utilizado sempre que um navegador precisa solicitar recursos de um servidor Web. Esses recursos podem ser páginas HTML, imagens, arquivos CSS, JavaScript, vídeos, dados de APIs e outros conteúdos.
Por exemplo ao acessar um site o navegador envia um request, então o servidor processa e envia uma response.

Detalhes dos campos da requisição

Campo Exemplo Descrição
Método GET Indica a operação que o cliente deseja realizar. GET é utilizado normalmente para solicitar um recurso.
URL/Caminho /index.html Indica o recurso que está sendo solicitado ao servidor.
Versão HTTP HTTP/1.1 Indica a versão do protocolo utilizada na comunicação.
Host www.exemplo.com Identifica o servidor ou domínio ao qual a requisição é destinada.
User-Agent Mozilla/5.0 Informa características do navegador ou programa que realizou a requisição.
Accept text/html Indica quais tipos de conteúdo o cliente consegue receber.
Accept-Language pt-BR Indica os idiomas preferidos pelo cliente.
Connection keep-alive Indica que a conexão pode ser mantida para outras requisições.
